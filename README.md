# Monday Morning Punchlines

One joke about Monday mornings, 200 characters at most, judged on laughs.

## The entry

> Monday morning: my bed filed a missing-person report on me — and the police sided with the bed.

## Run

```sh
python3 main.py
```

`main.py` prints the joke and writes it to `/output/entry.txt`.
